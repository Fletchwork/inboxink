# Architecture decision records

Why InboxInk is built the way it is, what was considered and rejected, and when to revisit.
Read the index before planning a change, and add a record in the same pull request as any
significant decision. Start from [template.md](template.md).

A record is immutable once accepted. If a decision changes, write a new record that supersedes it
and update the old one's status to point at the new one.
